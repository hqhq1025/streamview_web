# Audio Library

**URL**: https://studio.youtube.com/channel/UCtxQrYzeMBCKMAofCgcY5dA/audiolibrary
**Depth**: 1

## Overview
The Audio Library is a comprehensive resource within YouTube Studio that provides creators with access to copyright-free music and sound effects for use in their videos. The library offers a vast collection of audio tracks with various genres, moods, and categories that can be filtered, searched, and previewed before downloading.

## Main Components

### Tab Navigation
- **Music Tab**: Contains royalty-free music tracks organized by genre, mood, artist, duration, and license type
- **Sound Effects Tab**: Provides sound effects organized by category (Ambiences, Transportation, Cartoon, Animals, Horror, Tools, etc.)
- **Starred Tab**: Displays user's bookmarked/favorite audio tracks for quick access

### Search and Filter Bar
- **Search Box**: Allows searching by track title, mood, artist name, duration, or license type
- **Genre Filter**: Quick filter buttons on each track for filtering by genre (Hip-Hop & Rap, R&B & Soul, Pop, Rock, Ambient, Dance & Electronic, Alternative & Punk, etc.)
- **Mood Filter**: Quick filter buttons for filtering by mood (Calm, Sad, Funky, Bright, Happy, Dramatic, Romantic, Inspirational, etc.)
- **Artist Filter**: Quick filter for filtering by specific artists
- **Active Filters Display**: Shows currently applied filters with remove buttons
- **Filter Dialog**: Advanced filtering options with checkboxes for multiple selections

### Audio Track Listing
Each track displays:
- **Play/Pause Button**: Preview the audio track directly in the browser
- **Star Button**: Add or remove track from favorites
- **Track Title**: Name of the audio track
- **Genre**: Music genre (clickable filter)
- **Mood**: Emotional tone (clickable filter)
- **Artist**: Artist name with link to their channel (clickable filter)
- **Duration**: Track length
- **License Type**: YouTube Audio Library License information
- **Added Date**: When the track was added to the library
- **Download Button**: Download the audio file for use in videos

### Pagination Controls
- **Rows per Page**: Selectable option (30 rows default)
- **Page Navigation**: First, Previous, Next, Last page buttons
- **Result Counter**: Shows current range and total results (e.g., "1–30 of about 1,584")

## Functionality

### Browsing and Discovery
1. **Browse by Tab**: Switch between Music, Sound Effects, and Starred tabs
2. **Scroll Through Results**: Paginated list with 30 items per page
3. **Sort by Column**: Click column headers to sort by Track Title, Artist, Duration, or Added date

### Searching and Filtering
1. **Basic Search**: Type in search box to search across track titles, moods, artists, durations
2. **Filter Selection Dialog**: Click in search box to open filter options
3. **Quick Filters**: Click genre, mood, or artist tags directly on tracks
4. **Multiple Filters**: Combine multiple filters (e.g., Genre + Mood)
5. **Remove Filters**: Click X button on active filter or "Remove filter" button

### Audio Preview
1. **Play Track**: Click play button to preview audio
2. **Pause/Stop**: Click again to pause playback
3. **Visual Feedback**: Play button changes during playback

### Favorite Management
1. **Star Track**: Click star button to add to favorites
2. **Unstar Track**: Click star button again to remove from favorites
3. **View Starred**: Switch to Starred tab to see all favorited tracks
4. **Auto-save**: Changes are saved automatically with "All changes saved" confirmation

### Download
1. **Click Download**: Download button on each track
2. **License Information**: View license terms by clicking license type icon

## Interactive Elements

### Buttons
- **Play/Pause**: Preview audio tracks
- **Star/Unstar**: Manage favorite tracks
- **Download**: Download audio files
- **Filter**: Apply genre, mood, or artist filters
- **Remove Filter**: Clear active filters
- **Apply**: Apply selected filters in dialog
- **Close**: Close filter dialogs
- **Navigate Pages**: First, Previous, Next, Last pagination buttons

### Clickable Elements
- **Genre Tags**: Filter by genre
- **Mood Tags**: Filter by mood
- **Artist Names**: Filter by artist or visit their channel
- **Column Headers**: Sort by column
- **Track Title**: View track details (if available)
- **License Type**: View license information
- **Tab Navigation**: Switch between tabs
- **Search Box**: Open filter dialog

### Forms
- **Search Input**: Text input for searching and filtering
- **Filter Dialog**: Checkbox-based multi-select filters for:
  - Moods (Angry, Bright, Calm, Dark, Dramatic, Funky, Happy, Inspirational, Romantic, Sad)
  - Additional categories (Duration, License type, etc.)

### Dynamic Content
- **Filter Updates**: Results update instantly when filters are applied
- **Search Suggestions**: Filter dialog shows available search categories
- **Active Filter Chips**: Visual indicators of currently applied filters
- **Star State Changes**: Star button toggles between starred/unstarred states
- **Pagination**: Dynamic page counts based on filtered results

## Notable Observations

### Collection Size
- **Music Library**: Approximately 1,584 tracks available
- **Sound Effects**: Approximately 637 sound effects available
- **Diverse Artists**: Multiple artists including "The Grey Room" artists (Density & Time, Clark Sims, Golden Palms), Dyalla, NEFFEX, Jeremy Blake, and more

### Content Variety
- **Genres**: Hip-Hop & Rap, R&B & Soul, Pop, Rock, Ambient, Dance & Electronic, Alternative & Punk
- **Moods**: Calm, Sad, Funky, Bright, Happy, Dramatic, Romantic, Inspirational, Dark, Angry
- **Sound Effect Categories**: Ambiences, Transportation, Cartoon, Animals, Horror, Tools
- **Duration Range**: From 0:01 to 5:37 for music; various lengths for sound effects

### License Information
- **YouTube Audio Library License**: Standard license for most tracks
- **Attribution Requirements**: Some tracks may require attribution
- **Commercial Use**: Tracks can be used in monetized videos

### User Experience Features
- **Instant Preview**: No need to download to hear tracks
- **Persistent Filters**: Active filters remain when switching tabs
- **Responsive Feedback**: "All changes saved" messages confirm actions
- **Empty States**: Friendly message in Starred tab when no tracks are starred
- **Keyboard Accessibility**: Tab and Enter key navigation supported

### Technical Details
- **Lazy Loading**: Paginated results for performance
- **Real-time Filtering**: Instant search and filter results
- **Auto-save**: Star/unstar actions save automatically
- **URL Structure**: Uses /music path for Audio Library page
- **Accessibility**: Proper ARIA labels and roles for screen readers
